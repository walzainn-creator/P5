# PS5 Oman Parts Inventory

صفحة عربية جاهزة لـ GitHub Pages لإدارة كتالوج وجرد قطع غيار وملحقات PlayStation 5.

## المزايا
- بحث وتصفية حسب القسم والموديل وحالة المخزون.
- سعر بالريال العُماني.
- كمية المخزون مع +1 و-1 وتصفير.
- حفظ تلقائي داخل المتصفح عبر localStorage.
- تصدير CSV للجرد.
- كتالوج يشمل قطع الجهاز، قارئ الأقراص، التبريد، الطاقة، المنافذ، الهيكل، DualSense والملحقات.

## التشغيل
1. ارفع `index.html` إلى مستودع GitHub جديد.
2. من Settings → Pages اختر Deploy from a branch.
3. اختر `main` ثم `/root` واضغط Save.
4. بعد دقائق يظهر رابط GitHub Pages.

## ملاحظة
قائمة القطع هي كتالوج عملي واسع وليست ادعاءً بأن كل قطعة متوفرة فعلياً في سلطنة عُمان. أدخل مخزون محلك وأسعارك. بعض القطع تختلف حسب CFI وإصدار DualSense، لذلك يجب مطابقة الموديل قبل البيع أو التركيب.
